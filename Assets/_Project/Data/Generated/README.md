# Generated prototype card data

Everything in this folder is generated by **TCG > Generate Prototype Card Data**. It is safe to delete this folder and regenerate: the same settings and seed produce the same card ids, names, tiers and prices.

- `Cards/`: one CardDefinition per card, with ids like `SetA_Holo_02` (set, tier code, number).
- `SetA.asset`: the card set. The default pack configuration points here.
- `Materials/`: URP Lit materials whose colours come from the Rarity Palette (`Data/Visuals/RarityPalette.asset`).
- `Prefabs/`: `BoosterPack` (pack prop) and `WorldCard` (world-space card, filled by `WorldCardView`).
- `UI/`: `CardTemplate.uxml` and `.uss`, the UI Toolkit card template (filled by `CardTemplate.Bind`).

Don't hand-edit these assets. Change the generator settings, the Rarity Palette or the Tier Price Table (`Data/Balance/TierPrices.asset`), then regenerate. While this folder is deleted, anything that references it (such as the pack's card set) is broken until you regenerate; the generator re-links the default pack.
