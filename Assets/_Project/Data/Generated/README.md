# Generated card data

Everything in this folder is generated by **TCG > Generate Card Data** from the CSV manifests in `Data/Manifests/` (`Sets.csv`, one card file per set, `TierPrices.csv`). Edit the CSVs, never these assets, then regenerate.

- `Cards/<setId>/`: one CardDefinition per manifest row, named by its id (`RC_C_014`).
- `<setId>.asset`: one card set per `Sets.csv` row. Pack configurations point at these.
- `Materials/`: URP Lit materials whose colours come from the Rarity Palette (`Data/Visuals/RarityPalette.asset`).
- `Meshes/`: the booster pack's body and top strip (`PackMeshBuilder`), split along the zigzag crimp so the strip can be torn away.
- `Prefabs/`: `BoosterPack` (body, hinged top strip, cards inside, animated by `BoosterPackView`) and `WorldCard` (world-space card, filled by `WorldCardView`).
- `UI/`: `CardTemplate.uxml` and `.uss`, the UI Toolkit card template (filled by `CardTemplate.Bind`).

The generator upserts by id: new rows create assets, changed rows update them in place (same GUID), and rows that disappeared are reported, never deleted. Assets are never deleted and re-created, so scene and pack references survive a regeneration; after a run it re-links known references and reports any it couldn't.
